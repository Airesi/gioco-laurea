# Emporio del Dott. Martin — 101 e disonore

Menu mobile per la festa di laurea, pensato per GitHub Pages.

## Modificare il menu
Apri **menu.js**. Tutti i prodotti sono lì.

- `name`: nome
- `description`: descrizione
- `price: 30`: 30 E¢
- `price: 0`: GRATIS
- `premium: true`: evidenzia la voce
- `badge`: etichetta opzionale
- `available: false`: nasconde la voce senza cancellarla

Puoi aggiungere/rimuovere oggetti copiando le righe esistenti.

## Pubblicazione
Il sito è statico e compatibile con GitHub Pages. In GitHub: **Settings → Pages → Deploy from a branch → main / root**.

La pagina principale è `index.html`.
